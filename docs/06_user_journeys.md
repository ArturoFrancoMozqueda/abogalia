# User Journeys

## Cliente

```text
Descubre Abogalia
→ Selecciona una situación
→ Completa intake inicial
→ Recibe opciones compatibles
→ Compara perfiles
→ Selecciona servicio
→ Reserva
→ Paga
→ Comparte información adicional
→ Recibe recordatorios
→ Asiste a consulta
→ Evalúa la experiencia
→ Contrata servicio adicional
→ Gestiona seguimiento
```

## Abogado

```text
Se registra
→ Verifica identidad
→ Verifica cédula
→ Configura perfil
→ Define servicios
→ Configura disponibilidad
→ Recibe solicitud
→ Revisa resumen
→ Valida conflicto
→ Acepta o rechaza
→ Realiza consulta
→ Registra resultado
→ Da seguimiento
→ Convierte a cliente
→ Administra asunto
```

## Despacho

```text
Crea organización
→ Registra oficinas
→ Invita abogados
→ Configura roles
→ Define especialidades
→ Configura enrutamiento
→ Recibe solicitudes
→ Asigna abogado
→ Supervisa SLA
→ Convierte
→ Analiza resultados
```

## Operaciones

```text
Recibe solicitud de verificación
→ Revisa documentos
→ Aprueba o rechaza
→ Monitorea actividad
→ Atiende reportes
→ Gestiona disputas
→ Procesa reembolsos
→ Modera reseñas
→ Suspende cuando corresponde
```

## Intake progresivo

### Etapa 1 — Preclasificación

- Situación.
- Ubicación.
- Fecha.
- Urgencia.
- Modalidad.
- Descripción breve.

### Etapa 2 — Selección

- Compatibilidad.
- Servicio.
- Precio.
- Horario.

### Etapa 3 — Conflicto

- Nombres mínimos de partes.
- Relación.
- Organización relacionada.

### Etapa 4 — Preparación

- Documentos.
- Información adicional.
- Consentimientos.

### Etapa 5 — Consulta

- Sesión.
- Resultado.
- Siguientes pasos.

## Escenarios alternativos

- No existen abogados.
- El abogado rechaza.
- El abogado no responde.
- El usuario cancela.
- El abogado cancela.
- Pago falla.
- Se requiere otra especialidad.
- Existe conflicto.
- Se detecta urgencia.
- La solicitud no puede atenderse.
