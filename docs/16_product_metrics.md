# Métricas del Producto

## North Star Metric

> Consultas legales completadas con compatibilidad confirmada.

## Definición

Cuenta cuando:

- Existe reserva.
- Existe aceptación.
- Ambas partes asisten.
- El asunto corresponde al profesional.
- No existe reembolso total.
- Se confirma finalización.
