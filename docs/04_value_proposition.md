# Propuesta de Valor

## Para personas

### Promesa

> Encuentra al abogado adecuado para tu situación, verifica su información y reserva una consulta con condiciones claras.

### Valor

- Menor incertidumbre.
- Menos tiempo buscando.
- Mayor transparencia.
- Mayor confianza.
- Mejor preparación.
- Acceso digital.
- Seguimiento centralizado.

## Para abogados

### Promesa

> Recibe consultas mejor calificadas y administra prospectos, agenda, pagos y clientes desde una sola plataforma.

### Valor

- Mejor calidad de prospectos.
- Menor trabajo administrativo.
- Menos no-shows.
- Mayor conversión.
- Cobro anticipado.
- Presencia profesional.
- Medición de resultados.
- Operación centralizada.

## Para despachos

### Promesa

> Centraliza la adquisición, asignación y seguimiento de asuntos legales en una plataforma diseñada para equipos.

### Valor

- Distribución inteligente.
- Gestión de capacidad.
- Roles.
- Sedes.
- Reportes.
- Estandarización.
- Trazabilidad.
- Gestión comercial.

## Diferenciación frente a Google

Google permite encontrar opciones, pero no:

- Clasifica la situación.
- Verifica compatibilidad.
- Muestra disponibilidad real.
- Controla reserva.
- Administra pago.
- Mantiene historial.
- Valida reseñas mediante transacciones.

## Diferenciación frente a directorios

Abogalia no entrega únicamente nombres y teléfonos. Controla el proceso de principio a fin.

## Diferenciación frente a software jurídico

Abogalia comienza antes del expediente:

```text
Descubrimiento
→ Prospecto
→ Consulta
→ Contratación
→ Cliente
→ Asunto
```

## Diferenciación frente a plataformas de leads

- No vender el mismo contacto sin control.
- No cobrar por prospectos irrelevantes.
- Mostrar contexto estructurado.
- Permitir aceptación o rechazo.
- Medir calidad.
- Integrar operación y seguimiento.
